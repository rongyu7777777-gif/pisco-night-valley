# Pisco — Behind the Curtain

Public Pisco cinematic journey across six worlds, with seven generated TapNow clips, reversible prop-led camera travel and synchronized story choices.

This repository contains the deployable static website. GitHub Pages publishes the root of the `main` branch.

The complete 24-shot storyboard, seven individual clips and a full 1080p preview are available at `storyboard.html`. The current artwork includes the revised soft-CG athletes and adult female elven queen. Automatic viewing uses native video playback; manual travel holds decoded frames during seeking so idle frames stay stable.

## Update

Build the current site, replace the static HTML and assets, then push to `main`. The `.nojekyll` file keeps the static output unchanged.
